Documentos específicos de Categoría B de riesgo (según Anexo A).

Categoría determinada para el proyecto SGCV-IA: el estudio trabaja con datos
de propietarios de mascotas y de clínicas veterinarias (información personal
identificable de terceros), pero no involucra menores de edad como
participantes directos ni datos reales de transacciones financieras, por lo
que corresponde a Categoría B y no a Categoría A o C.

Documentos incluidos:

- `B2_Proteccion_Datos_Personales.pdf` — Protocolo de Protección de Datos
  Personales de Propietarios.
- `B3_No_Uso_Datos_Reales.pdf` — Compromiso de No Uso de Datos Reales de
  Transacciones.
- `B5_Datos_Menores.pdf` — Política de Manejo de Datos de Menores
  (documento preventivo: aplica aunque el estudio no reclute menores,
  para cubrir el caso de que un propietario menor de edad participe
  incidentalmente).
